# ManyManager Simple 0.3.0

- שני מחשבונים עצמאיים, עם תקציבים, הוצאות, קטגוריות ותתי־קטגוריות ואמצעי תשלום נפרדים.
- שני כפתורי הוספת הוצאה סגולים ושני סיכומים נפרדים במסך הבית.
- ניהול המחשבון השני דרך כניסה חדשה מתחת להגדרות.
- שינוי שמות קטגוריות ותתי־קטגוריות תוך שמירת המזהים ושיוכי ההוצאות.
- תמיכה בעברית, רוסית ואנגלית, בכיווני RTL/LTR ובמצב בהיר וכהה.

## נתונים והתקנה

נתוני המחשבון הקיים נשמרים במחשבון הראשי. המחשבון השני מתחיל ריק; תקציב חדש מתחיל באפס, ללא העברה אוטומטית בין תקופות. מסד הנתונים נשאר בסכמה 3, כולל מסלולי השדרוג הנתמכים.

מזהה החבילה הוא `com.manymanager.privateversion`. הרליס הישן 0.2.0 השתמש בחבילה אחרת; הגרסה הזו מותקנת בנפרד ואינה מעבירה ממנה נתונים אוטומטית. נתונים אינם משותפים בין החבילות. אין להסיר התקנה קיימת או לנקות נתונים כדי לפתור הבדל חתימה בין גרסת פיתוח לרליס.

## אימות

קוד התכונה עבר בנייה ו־lint, ‏33 בדיקות JVM, ‏83 בדיקות במכשיר Samsung ו־1,137 בדיקות HTML. הבדיקות כוללות בידוד מחשבונים, אתחול חוזר ומקביל, פתיחה מחדש של מסד מאוכלס, שחזור טפסים, גבולות תקופה ופריסות שפה/עיצוב.

לא נבדקו API 30, גיבוי/העברת מכשיר בפועל, נגישות ידנית מלאה או מוות תהליך במהלך שמירה. תוצאות אלו אינן מבטיחות התאמה מלאה בין דפדפנים.
